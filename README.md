## Опис індивідуального завдання

1. Табулювання кусочно-неперервної функції на проміжку [0, 6] із кроком h = 0.3 з використанням конструкцій `if-elif-else`, тернарного оператора та циклу `for`:
   y = \begin{cases} \cos(x) + e^{-x}, & x \le 1 \\ \sqrt[3]{x^2 + 7}, & 1 < x < 4 \\ \frac{1}{x^2 - 15}, & x \ge 4 \end{cases}

2. Обчислення суми нескінченного числового ряду із заданою точністю \varepsilon = 10^{-7} за допомогою циклу `while` та рекурентного співвідношення (|x| < 1):
   \frac{1}{1+x^2} = \sum_{k=0}^{\infty} (-1)^k x^{2k}
   Базовий член ряду: a_0 = 1
   Рекурентне співвідношення:** a_k = a_{k-1} \cdot (-x^2)
   Еталонна функція: `1.0 / (1.0 + x**2)`
